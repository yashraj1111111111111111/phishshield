# 90-second demo script

1. “Students and parents receive KYC, parcel, prize, and job scams, but the warnings are usually technical.”
2. Paste the safe example message into PhishShield and press **Check safely**.
3. Point out the risk score, raw-IP finding, urgency/OTP warning, explanation, and 12-digit scan reference.
4. Switch to Hindi to show inclusive explanations (with Ollama enabled).
5. Explain that links are never opened, so checking them does not expose the user to the destination.
6. “Under the hood, the API also slows abusive scan bursts and logs campaign-like activity. An optional neural network adds a second phishing-confidence signal.”
